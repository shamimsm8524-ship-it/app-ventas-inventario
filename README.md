# Mi Negocio — Ventas e Inventario

Aplicación web para administrar productos, categorías, stock y ventas desde celular o computadora.

## Funciones incluidas

- Registro de productos por categoría.
- Imagen del producto desde cámara o galería.
- Código de barras manual y escaneo con cámara cuando el navegador lo permite.
- Precio de compra y precio de venta.
- Stock y unidad de medida.
- Buscador por nombre, categoría o código.
- Filtro por categorías.
- Aviso visual de stock bajo.
- Nueva venta con carrito.
- Descuento automático de stock al cobrar.
- Historial de ventas.
- Total vendido durante el día.
- Datos guardados localmente en el dispositivo para esta primera versión.
